# Art Mood — فروشگاه + پنل مدیریت

## مسیرها
- `/` فروشگاه
- `/admin.html` پنل مدیریت

## امکانات پنل
- ورود مدیر
- داشبورد سفارش‌ها و درآمد
- مشاهده سفارش‌ها
- تغییر وضعیت سفارش
- افزودن/ویرایش محصول
- تغییر موجودی
- غیرفعال‌کردن محصول از طریق API
- هشدار موجودی کم

## راه‌اندازی
`npm install`
سپس `.env` را از `.env.example` بساز و رمز مدیر و Merchant ID را تنظیم کن.
بعد:
`npm start`

### امنیت تولید
این نسخه اسکلت عملیاتی است. برای محیط واقعی حتماً:
- دیتابیس PostgreSQL/MySQL به جای Map
- هش/هش‌کردن امن رمز مدیر (Argon2/bcrypt) و session در Redis/DB
- HTTPS
- CSRF protection برای پنل مبتنی بر cookie
- rate limiting و audit log
- اعتبارسنجی دقیق ورودی‌ها
- آپلود امن تصاویر (object storage)
- نقش‌های مدیریتی در صورت نیاز
اضافه شود.
